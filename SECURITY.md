# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a vulnerability or critical numerical calculation defect that violates model risk safeguards (SR 11-7 / SR 26-2), please report it via private security advisory on GitHub or email the maintainers directly.
